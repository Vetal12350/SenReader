# SenReader

**Лёгкая читалка манги и манхвы для Android — без рекламы, регистрации и лишнего.**

Каталог и поиск по Senkuro и ReadManga, плавная лента для вебтунов,
закладки и уведомления о новых главах. Всё хранится на телефоне.

## Что умеет

| | |
|---|---|
| 📚 **Каталог и поиск** | Один поиск сразу по Senkuro и ReadManga. Одинаковые названия объединяются в одну карточку, у каждой книги — свой активный источник. |
| 📜 **Лента для вебтунов** | Непрерывная вертикальная прокрутка с переходом в следующую главу без меню. Глава заранее скачивается на телефон, поэтому страницы не подгружаются на глазах. |
| 🔖 **Библиотека** | Статусы «Читаю», «В планах», «Прочитано», «Заброшено», избранное, отметки прочитанных глав и точная страница, на которой вы остановились. |
| ▶️ **Читаемое сейчас** | На главной — последние тайтлы с сохранённой страницей. Дочитанные до последней вышедшей главы скрываются сами. |
| 🔔 **Новые главы** | Фоновая проверка книг со статусом «Читаю» примерно раз в час. Новые главы попадают в ленту «Уведомления» и, по желанию, в системные уведомления Android. |
| 🌗 **Темы** | Тёмная, светлая или как в системе. |
| 💾 **Резервная копия** | Сохранение библиотеки в файл и восстановление из него — без потери прогресса. |
| ☁️ **Синхронизация** *(по желанию)* | Вход через Google или почту, чтобы библиотека была одинаковой на нескольких устройствах. Без входа всё работает полностью локально. |

## Установка

1. Скачайте файл **`SenReader-*.apk`** из раздела [**Releases**](../../releases).
2. Откройте его на телефоне и разрешите установку из этого источника, если Android спросит.
3. Готово: откройте SenReader и найдите первую мангу через поиск.

> **Обновление.** Новую версию ставьте поверх старой — закладки и прогресс сохранятся.
> Не удаляйте приложение перед обновлением: вместе с ним удалятся и данные.
> На всякий случай сделайте копию: **Настройки → Резервная копия библиотеки → Сохранить копию в файл**.

## Чтобы уведомления приходили вовремя

Android экономит батарею и может откладывать фоновые проверки на часы. Чтобы этого не было:

1. **Настройки** (шестерёнка на главной) → раздел **«Уведомления»**.
2. Включите **«Автоматически искать новые главы»** и, если нужно, **«Системные уведомления Android»**.
3. В строке **«Фоновые проверки без ограничений батареи»** нажмите **«Разрешить»** и подтвердите.

На время проверки появляется тихое уведомление «Проверка новых глав…» — так Android не прерывает её.
Пока вы читаете главу, проверка ждёт, чтобы не мешать прокрутке.

<details>
<summary><b>Xiaomi, Samsung, Huawei и другие</b></summary>

У некоторых производителей есть собственные «оптимизаторы», которые закрывают приложения в фоне.
Найдите SenReader в настройках батареи или автозапуска и разрешите работу в фоне без ограничений.
Подробные инструкции для каждой марки собраны на [dontkillmyapp.com](https://dontkillmyapp.com/).

</details>

## Приватность

- **Без аккаунта** всё хранится только на телефоне: библиотека, прогресс, настройки.
- **С аккаунтом** библиотека синхронизируется в ваш личный раздел облака; другие пользователи его не видят.
- Нет рекламы, аналитики и счётчиков. Нет комментариев, профилей и ленты активности — только чтение.

## Честно о границах

- SenReader **не хранит и не распространяет** мангу: страницы загружаются с сайтов-источников так же, как в браузере.
- Платные, закрытые и удалённые главы остаются недоступными — читалка не обходит авторизацию, CAPTCHA и ограничения сайтов.
- Сайты могут менять свою разметку или временно блокировать запросы — тогда источник может перестать работать до обновления приложения.
- Новые главы проверяются по расписанию Android, а не мгновенно: обычно в течение часа-нескольких часов после выхода.
- Пожалуйста, уважайте авторов и переводчиков: поддерживайте их на официальных площадках.

## Для разработчиков

<details>
<summary><b>Сборка из исходников</b></summary>

Нужны Flutter SDK (проверено на **3.47.9**) и Android SDK. Папка `android/` не хранится в репозитории и создаётся при сборке:

```bash
flutter create --project-name senreader --org app.senreader --platforms android .
python scripts/prepare_android.py
flutter pub get
flutter test
flutter build apk --release
```

`prepare_android.py` настраивает манифест, иконки, разрешения (интернет, уведомления, фоновые проверки)
и подпись. Для подписи положите `android/key.properties` со ссылкой на собственный ключ —
**никогда не коммитьте ключи и пароли**. Без него сборка подписывается временным debug-ключом,
и такой APK не встанет поверх версии с другой подписью.

</details>

<details>
<summary><b>Устройство проекта</b></summary>

| Путь | Что там |
|---|---|
| `lib/main.dart` | оболочка приложения, главная, каталог, библиотека |
| `lib/ui/reader_page.dart` | ридер: лента, предзагрузка, сохранение позиции |
| `lib/data/*_source.dart` | адаптеры источников Senkuro и ReadManga |
| `lib/data/library_store.dart` | локальная библиотека и прогресс |
| `lib/data/chapter_*.dart` | очередь и фоновая проверка новых глав, лента уведомлений |
| `lib/data/page_disk_cache.dart` | дисковый кеш страниц |
| `test/` | более 470 автоматических тестов |
| `docs/` | архитектурные заметки и разборы |

Сборка и тесты выполняются в GitHub Actions (`.github/workflows/android-apk.yml`).
Правила для ИИ-ассистентов — в [AGENTS.md](AGENTS.md).

</details>

<details>
<summary><b>Плавность и производительность</b></summary>

Лента вебтуна измерялась на Pixel 8 Pro (120 Гц) системной статистикой SurfaceFlinger и трассировкой Perfetto.
Главное, что сделано: фоновые проверки и облачная синхронизация не работают во время чтения,
страницы глав заранее сохраняются на диск, их размеры берутся из заголовков файлов до декодирования,
несколько следующих страниц декодируются заранее. Подробности — в [docs/](docs/).

</details>
