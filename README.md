# SenReader 0.1 — исходники Android-читалки

**Статус: первая реализация, не готовый релиз и не проверенный APK.**

Flutter-приложение с тёмным интерфейсом, единым каталогом, поиском по трём источникам: Senkuro, ReadManga и ReManga,
консервативным объединением одинаковых названий, просмотром глав, избранным и локальным
прогрессом чтения. Никакие материалы сайтов в пакет не включены.

## Что реализовано
- Главная, каталог, библиотека (тёмная тема)
- Публичные GraphQL-запросы Senkuro для каталога, поиска, карточек, глав, изображений
- HTML-парсер ReadManga для каталога, поиска, карточек, глав, изображений
- ReManga API v2 для каталога, поиска, карточек и публичных глав без авторизации
- Объединение результатов **только с одинаковым нормализованным названием**; ручная
  связка тайтлов с различными названиями будет добавлена позже
- Компактное меню «Сменить источник» на карточке. У сохранённой книги один активный
  источник для чтения и проверок новых глав; только явный выбор меняет его.
  Для несохранённых книг при ошибке допускается перебор совпавших источников.
- Локальное сохранение избранного и последней отмеченной прочитанной главы
- Ручная проверка новых доступных глав в «Настройках», только у активного источника
  каждой книги: первая успешная проверка источника сохраняет базовый список без
  исторических уведомлений, повторная сообщает только о новых главах.
  Номера (включая дробные) и тома сопоставляются без учёта текста подзаголовка.
- Опциональные локальные уведомления Android и WorkManager с периодом 15 минут
  (минимум WorkManager, фактические проверки могут задерживаться Android).
  Однократное предложение после добавления книги или открытия библиотеки ничего
  не включает автоматически; отказ/закрытие запоминается. Только явное включение
  запрашивает разрешение Android 13+. Переключатель доступен в «Настройках».
  Старые интервалы переводятся на 15 минут; открытие уведомления повторно проверяет
  доступность главы и запускает её внутри SenReader.
- Глаз слева от главы: перечёркнутый — не прочитано, открытый — прочитано.
  Отметка включает все доступные более ранние главы, включая прошлые тома;
  снятие отметки касается только выбранной главы. Позиция страницы сохраняется
  отдельно. Подробнее: [чтение, источники и уведомления](docs/reading_and_alerts.md).

## Для сборки APK (Windows / macOS / Linux с Flutter SDK)
1. Установить Flutter SDK и Android SDK: https://docs.flutter.dev/get-started/install
2. Распаковать этот архив в папку `SenReader`, открыть терминал в этой папке.
3. Запустить:

   ```bash
   flutter create --project-name senreader --org app.senreader --platforms android .
   python scripts/prepare_android.py
   flutter pub get
   flutter test
   flutter build apk --debug
   ```

4. Установочный файл: `build/app/outputs/flutter-apk/app-debug.apk`.
   Для настоящего релиза используйте собственную подпись (не публиковать ключ).

Приложение не требует сервера, работает на Android (в том числе Google Pixel 8 Pro).

## Получить APK через GitHub Actions (без установки Flutter локально)
1. Создать свой **приватный** репозиторий GitHub `SenReader` и загрузить туда содержимое папки.
2. Открыть вкладку **Actions** → **Build Android APK** → **Run workflow**.
3. После успешного запуска скачать артефакт **SenReader-debug-APK** (в ZIP лежит APK).

Для открытия приватного репозитория и запуска Actions потребуется аккаунт GitHub.
Пайплайн создан, но не запускался в текущей среде.

## Ограничения и открытые вопросы
- Среда разработки, в которой создан исходник, **не содержит Flutter/Android SDK**,
  поэтому проект не был скомпилирован и реальные HTTP-запросы не были проверены.
- Сайты могут возвращать 403/гео-блокировку, требовать сессию/авторизацию,
  менять HTML/API, блокировать изображения. Мы не обходим DRM, платные ограничения
  или CAPTCHA: недоступный контент остаётся недоступным.
- Разные переводы названия пока **не объединяются автоматически**.
- ReManga: неофициальный нестабильный API; реальные запросы и доступность глав здесь
  не проверены. Офлайн-тесты используют синтетические JSON-примеры форматов community adapter,
  а не ответы живого API. Ошибки HTTP/403 и изменённые форматы показываются как ошибки.
  Неопубликованные, заблокированные и платные главы исключаются (кроме `is_free_today == true`);
  `is_bought` игнорируется, так как сессии нет. Защищённые страницы недоступны.
  Используется первая ветка перевода, до 5 страниц по 500 записей; каталог/поиск — первые 30.
  Токены, cookies и обход ограничений не используются.
- Сведения о новых главах проверяются с задержкой: WorkManager не гарантирует
  немедленный запуск и может откладывать задачи в режиме энергосбережения.
  Без отдельного сервера нет мгновенных push-уведомлений о публикации.
  Доступность непубличных, платных и удалённых глав не обходится.
- Реальное получение уведомлений и переход в читалку ещё требуется
  проверить на Android-устройстве; успешная сборка APK не заменяет тест на телефоне.
- Прогресс чтения отмечается вручную кнопкой «Глава прочитана», главы пока
  не скачиваются, нет импорта библиотеки из существующих сервисов.
- Интерфейс выполнен «в духе» Senkuro, без их логотипов или закрытых ресурсов.
- Пользуйтесь источниками с соблюдением их условий и прав правообладателей.
